關於這個作品

多輪對話：每次送出時，把整段對話紀錄一起交給 OpenAI API，所以角色記得你前面說過什麼。角色的設定寫在伺服器上，訪客不能改寫。

重點整理：分成兩次呼叫：第一次只抓關鍵字，第二次把原文和關鍵字一起交給模型寫成短文，讓中間結果看得見。

前端放在 GitHub Pages，API 部署在 Vercel，金鑰只存在伺服器，並限制每分鐘的使用次數。本站不保存對話；生成內容可能有誤，請自行核對。
